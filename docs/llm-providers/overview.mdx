---
title: "GPT-6 Endpoints"
description: "Supported model and endpoint boundary"
---

LyraShield Engine accepts only deployment names recognized as GPT-6 Sol or Luna, plus the authenticated `chatgpt/gpt-6-*` subscription route for the main model. LiteLLM remains an internal model-client dependency; it does not make its broader provider catalog a supported LyraShield surface.

| Route | Supported use |
| --- | --- |
| OpenAI-compatible | Approved GPT-6 deployment with `LLM_API_KEY` and optional `LLM_API_BASE` |
| Azure AI / Azure OpenAI-compatible | Approved GPT-6 deployment with Azure endpoint, credential, and API-version aliases |
| ChatGPT subscription | Authenticate with `lyrashield auth login chatgpt`, then select `chatgpt/gpt-6-luna` or `chatgpt/gpt-6-sol` for the main model only |

Anthropic, Bedrock (including `bedrock_mantle`), Vertex, OpenRouter, Novita, local models, and subscription-backed models outside `chatgpt/*` are unsupported as LLM endpoints and rejected. Perplexity and Parallel are not supported as LLM endpoints. Parallel Search may be used as an optional `web_search` tool when explicitly enabled; see Configuration.

Subscription notes: the `chatgpt/` route is enabled by default in the standalone engine (`LYRASHIELD_ALLOW_CHATGPT_SUBSCRIPTION=0` disables it), restricted to `STRIX_LLM`/`LYRASHIELD_LLM` — delegate and dedupe models must use a metered OpenAI or Azure/Azure AI route — and records `auth_mode: "subscription"` with `llm_usage.cost: 0`. The production worker disables subscription routing.

The application worker resolves the preset before spawning the engine: Safe/Quick/Standard use Luna with medium reasoning throughout. Deep/Custom use Sol with medium reasoning for the root coordinator and Luna with high reasoning for focused child specialists. The route is deterministic: only the root can create or stop specialists, child agents cannot promote themselves or recursively fan out, and Sol retains final cross-file judgment. `LYRASHIELD_LLM` remains the explicit primary fallback; `LYRASHIELD_DELEGATE_LLM` configures the bounded specialist tier.
