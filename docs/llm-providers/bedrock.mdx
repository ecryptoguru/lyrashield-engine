---
title: "AWS Bedrock"
description: "Not supported as a LyraShield LLM endpoint"
---

<Warning>
AWS Bedrock routes — including `bedrock_mantle` — are not supported by
LyraShield Engine. Production accepts only approved GPT-6 Sol or Luna
deployments through the documented OpenAI, Azure/Azure AI, or authenticated
`chatgpt/` provider boundary. This unlinked page is retained only to make the
inherited upstream documentation history explicit.
</Warning>

Earlier revisions admitted a `bedrock_mantle/openai.gpt-*` route; that provider
marker is no longer in the GPT-6 admission allowlist and is rejected before
scan start. Do not configure Bedrock credentials in the worker.
