# Independent bounded package inventory

`scripts/verify_sandbox_package_inventory.py` is a read-only verifier for immutable native amd64/arm64 OCI bytes. It does not publish an image, run its code, move tags, dispatch workflows, or remove the publisher's promotion hold. A successful result is only `bounded_scope_matched`, with `releaseQualified: false` and explicit limitations.

The operator supplies the expected index digest, full engine/workflow revision, publisher run and attempt, local SHA-256-named OCI blobs, signed producer receipt files, a protected host Go metadata tool, an existing source repository containing the exact commit, and a private owned scratch directory. The CLI itself runs `gh attestation verify oci://IMAGE@DIGEST --bundle-from-oci` for provenance, qualification, SBOM and bounded coverage, while separately hashing the local index. The publisher stores its bundles in OCI without GitHub storage records. The verifier fixes the repository, image, signer workflow, `main` source ref and hosted-runner policy; certificate source/signer digests, invocation, subject and exact run must match. Saved producer verification JSON is never an authentication input. Historical selected source/workflow revisions that differ are outside this verifier's current policy.

Executable trust comes from protected source policy, not caller-supplied checksums or `PATH`. `/usr/bin/gh` must be the official Linux amd64 v2.95.0 binary with SHA-256 `62c11fbaa08835168c3d1acf8a645ac6268a13a5682c73581388c9df0c622617`; its official release archive is pinned to `25d1e4729e8808c9ed3d613e96ebd3f3e44446f2d368c89d878a71a36ddb3d8c`. The Go inspector must be Linux amd64 Go1.27.3, binary SHA-256 `5f5eb6d0b2fb6aa0bb5d5f8c5f1c944e0de955c925f0111af92a9d8f79680b5b`, from the publisher's checksum-pinned official archive `65efbc80fdc1fa2cd2631cad5b481777a68e8725f34e89f50fc6ac714e379b40`. Both tools and every parent directory must be root-owned, non-symlink and not group/world-writable; both authenticated producer receipts must also bind that exact Go tool hash. Provision these files only in future isolated protected qualification infrastructure. A Homebrew/macOS rehearsal cannot satisfy this policy or create qualifying output.

The flat blob directory must contain the exact index, both native manifests/configs, every compressed image layer, and both signed SPDX documents. Every opened blob is a bounded regular non-symlink file. The index's native descriptor digest, size, media type, config platform and ordered DiffIDs must agree with the signed predicates. Source labels must match the expected repository/revision. Producer receipts are accepted only when their exact bytes match the receipt digests in the authenticated coverage predicate. Go application manifests are read from the exact Git commit with replacement objects disabled.

The verifier makes a complete compressed-SHA-256 and uncompressed-DiffID pass through every layer. A conservative bounded header model applies ordered whiteouts and additions without extracting or following image paths. It uses an explicit 200,000-header policy; the existing prototype default remains 100,000. The 64 MiB retained-name bound and 10 million work cap remain unchanged. Indexed inode counts and whiteout paths avoid repeated whole-tree scans without dropping headers or hardlink semantics. It retains final-file source-layer extents. A second complete byte-verification pass copies only selected package metadata and twelve Go files into generated private filenames, with bounded total/per-file bytes and one payload file open at a time. An inert scoped archive retains the complete final header/link inventory and the selected contents. The existing Syft-independent Debian/Python/npm oracle rejects guarded aliases, incomplete scopes and missing typed purls. Repeated installed Debian `(Package, Architecture)` keys fail, including identical or contradictory versions; valid multiarch remains distinct. Go checks bind each exact file hash and ELF architecture to its SPDX file, main module, standard library and file-attributed effective dependencies. Independently observed counts and application evidence must also match the signed producer receipts.

The header/link model, package parsers and Go relationship checks are shared source with existing bounded oracle components. This is independent execution and independent OCI byte acquisition/reconstruction, not a second implementation of those parsers. Unsupported PAX, hardlink, path, changeset or resource-bound cases fail closed. No Linux runtime overlay equivalence, actual capability state, arbitrary binary/source-tree enumeration, other package ecosystems, universal SBOM completeness, adversarial robustness or benchmark result follows.

Run on an isolated Linux host with the publisher's checksum-pinned Go 1.27.3 linux/amd64 metadata inspector. Provision at least 8 GiB free private working space in addition to the downloaded blobs. The acquisition coordinator, verifier child and receipt binder enforce a 4 GiB per-process address-space cap, 1,800 CPU seconds and 256 descriptors. Metadata helpers have a 2 GiB address-space cap. These are per-process limits, not an aggregate memory reservation. The verifier has a 1,800-second wall alarm and its coordinator terminates/reaps it after 1,810 seconds. Go snapshots and tool output use the checked private scratch filesystem. Image paths and selected payloads must not be exposed in logs, materialized as host paths, or retained after qualification. The CLI removes its generated payload/archive/capture directories on success and failure; the coordinator owns cleanup of the input blobs, downloaded authenticated artifacts and output receipt.

```sh
python3 -m scripts.verify_sandbox_package_inventory \
  --blobs "$PRIVATE_BLOBS" --source-repository "$ENGINE_REPOSITORY" \
  --producer-receipts "$AUTHENTICATED_COVERAGE_RECEIPTS" \
  --scratch "$PRIVATE_SCRATCH" --output "$PRIVATE_SCRATCH/inventory-receipt.json" \
  --index-digest "$FINAL_INDEX_DIGEST" --revision "$FINAL_MERGED_ENGINE_REVISION" \
  --run-id "$PUBLISHER_RUN_ID" --run-attempt "$PUBLISHER_RUN_ATTEMPT" \
  --go-tool "$PINNED_GO_TOOL"
```

## Hosted acquisition and bounded evidence delivery

`verify-sandbox-inventory.yml` runs only from the protected engine repository's `main`, with fixed repository/owner checks. The acquisition job has read-only repository, Actions and package permissions while it downloads and independently verifies the native image bytes. Its result is bound to the exact verifier commit/tree, workflow/run/attempt and all 19 executed source/tool-provisioner/workflow files; actual checkout bytes must equal those immutable Git blobs. A separate GitHub-hosted job checks the same-run artifact identity, archive and receipt digests, bounded contents and selector/source bindings before obtaining registry-write and attestation permissions. It publishes a distinct `sandbox-independent-inventory/v1` OCI-backed GitHub attestation on the selected immutable index and retains the receipt artifact. It does not promote image tags, access production, use the managed fleet signer or qualify runtime authority. OCI delivery allows the product verifier to authenticate evidence without a new cross-repository artifact-download secret.

The coordinator requires the reviewed publisher workflow and exact successful native, evidence, signature and upload steps. Only its named final independent-coverage hold may fail; both promotion steps must be skipped and cleanup must succeed. Generic publisher failures are rejected. Current [publisher run 43124045901](https://github.com/ecryptoguru/lyrashield-engine/actions/runs/43124045901) completed both native builds and all evidence steps, ending at that deliberate hold. This is publication evidence, not independent inventory qualification.

Local verification passed 76 focused tests and 17 subtests; nine Linux-only cases were skipped on macOS. A separate isolated, unprivileged, network-disabled Linux arm64 container passed 14 resource/binding tests, with the real fixed-host Git fixture skipped because that cached image contains no `/usr/bin/git`. Those tests exercised a full separate 1 MiB temporary filesystem, checked-scratch placement, error redaction, address-space/descriptor/CPU exhaustion and child termination. The real Git source-binding fixture passed on macOS. Exact hosted amd64 Go/Git/OCI execution and the first signed independent result remain unverified until the workflow runs.
