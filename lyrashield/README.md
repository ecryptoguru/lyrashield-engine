# `lyrashield` package

This package is the intended home for LyraShield product-critical policy
(GPT-5.6 gating, environment aliases, telemetry/update defaults, and the
worker artifact contract).

For now the package is intentionally minimal while the controlled `strix/`
derivative retains the stable SDK plumbing and policy implementation.
Changes are tracked in `UPGRADES.md` and the `NOTICE` file.
